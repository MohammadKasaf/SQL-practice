# SQL Practice

This repository contains SQL practice notebooks covering concepts from beginner to advanced level. The notebooks are designed to provide hands-on SQL practice and strengthen problem-solving skills for Data Engineering, Data Analytics, Business Intelligence, and Databricks interviews.

## Topics Covered

- SELECT Statements
- WHERE Clause
- ORDER BY Clause
- GROUP BY Clause
- HAVING Clause
- SQL Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE WHEN Statements
- Views
- Indexes
- Stored Procedures
- Triggers
- Data Warehouse SQL
- Advanced SQL Concepts
- SQL Interview Questions

## Learning Objectives

By completing these notebooks, you will learn:

- SQL fundamentals and query writing
- Data filtering and sorting techniques
- Data aggregation and grouping
- Working with multiple tables using joins
- Writing and optimizing subqueries
- Using Common Table Expressions (CTEs)
- Solving analytical problems using window functions
- Implementing conditional logic with CASE WHEN
- Creating and managing database objects
- Understanding indexing concepts
- Working with stored procedures and triggers
- Applying SQL in Data Warehouse environments
- Solving real-world SQL interview questions
